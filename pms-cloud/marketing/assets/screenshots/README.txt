TAJ Pharmacy — marketing screenshots
=====================================

Drop your desktop-app screenshots into THIS folder using these exact file names.
The home page (index.html) already points to them. Until a file exists, the page
shows a clean dashed placeholder in its place — so the layout always looks intentional.

Required / expected files (PNG or JPG, but keep the .png name):

  hero.png        -> big screenshot in the top hero area
                     recommended ~1600 x 1000 px (16:10), the main "wow" shot
                     (e.g. the Dashboard or the POS screen)

  pos.png         -> POS / point-of-sale screen        (16:10, ~1200 x 750)
  inventory.png   -> Warehouse / inventory screen      (16:10, ~1200 x 750)
  reports.png     -> Reports / dashboard screen         (16:10, ~1200 x 750)

Tips:
- Use clean demo data (no real customer names) in the screenshots.
- PNG keeps text crisp. Keep each file under ~500 KB if you can (compress at tinypng.com).
- You can replace any image any time — just overwrite the file with the same name.
- If you want a different filename, update the matching <img src="..."> in index.html.
